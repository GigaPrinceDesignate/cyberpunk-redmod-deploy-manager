## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Load Order** | Drag-to-reorder REDmod deployment priority for all mods |
| **Mod Profiles** | Save named mod sets to switch between different configurations |
| **One-Click Deploy** | Deploy or revert any saved REDmod profile with a single click |
| **Conflict View** | See which REDmods modify the same files for conflict awareness |
